# Tarayıcı Önizleme Kontrol Notu

İlk dış bağlantı denetiminde HTML ulaşılabilir durumdaydı; ancak geçici sunucu kök yolundan servis edildiği için `preview.css` ve `preview.js` yolları 404 dönüyor, sayfa stilleri uygulanmıyordu. Önizleme sunucusuna kök yol varlık eşlemesi eklendi. İkonlar, GitHub Pages yalnızca `docs/` dizinini yayınlasa dahi erişilebilir olması için `docs/assets/` altında tutulacak biçimde düzenlendi. Düzenleme sonrasında önizleme sayfası, biçim ve etkileşim akışı tekrar doğrulanmalıdır.
